## 機能

- **クイズ作成** - 問題文・選択肢・正解を自由に設定できる
- **クイズ回答** - 作成したクイズを選択肢ボタンで回答
- **結果表示** - 全問終了後にスコアを表示
- **データ保存** - LocalStorageを使って、ブラウザを閉じてもクイズが残る
- **管理者モード** - ログインすることでクイズの削除が可能になる

---

## 使い方

### クイズを作る
1. ホーム画面から「クイズ作成画面へ」をタップ
2. クイズ名・問題文・選択肢を入力し、正解にチェックを入れる
3. 「＋ 新しい問題を追加」で問題を増やせる（最大100問）
4. 「問題集をすべて保存」で保存完了

### クイズで遊ぶ
1. ホーム画面に保存済みのクイズが表示される
2. クイズをタップしてスタート
3. 全問回答後にスコアが表示される

### 管理者としてログイン
1. 右上の「ログイン」ボタンをタップ
2. IDとパスワードを入力してログイン
3. 管理者モードでは各クイズに「削除」ボタンが表示される

## 技術的な工夫

- **シングルページアプリ（SPA）** - `quiz.html` 1ファイルで完結。ページ遷移をJavaScriptで制御し、画面リロードなしで複数の画面を切り替える
- **iOSライクなUI** - CSS変数でiOS標準カラーを再現し、統一感のあるデザインを実現
- **スライドアニメーション** - `transform: translateX` によるページ遷移でネイティブアプリに近い操作感
- **ブラウザ履歴対応** - `history.pushState` と `popstate` を使い、ブラウザの戻る・進むボタンに対応
- **バリデーション** - 未入力項目をリアルタイムで赤枠表示してユーザーに通知
- **権限制御** - ログイン状態に応じてUIを動的に切り替える管理者機能
